# dbt-Workbench Promotion Kit

This directory contains launch-ready material for promoting dbt-Workbench. It separates assets that
can be shipped in the repository from actions that require a human maintainer, external accounts, or
real user evidence.

## Start Here

1. Run the [activation checklist](activation-checklist.md) against a clean machine.
2. Collect at least three evaluator interviews before claiming adoption.
3. Use the [launch kit](launch-kit.md) for Hacker News, Product Hunt, and community posts.
4. Send the [partner brief](partner-brief.md) to dbt consultants and platform teams.
5. Track the funnel in `website/docs/analytics-setup.mdx` and the project analytics tools.

## Evidence Policy

Do not invent customer names, production metrics, testimonials, or adoption counts. Replace the
placeholders in `case-study-template.md` only after receiving permission from the user or team.

## Channel Cadence

- Weekly: one technical article, one useful community contribution, and five relevant outreach messages.
- Per release: one workflow demo and one changelog entry focused on user outcomes.
- Monthly: review activation, referral, search, and GitHub metrics; refresh underperforming pages.
