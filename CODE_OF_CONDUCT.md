# Code of Conduct

Welcome to dbt-Workbench! This project exists to give the dbt community a lightweight, open, vendor-neutral UI for browsing models, exploring lineage, running jobs, and managing environments. It gets better every time someone shares an idea, reports a bug, or opens a pull request, so we want everyone to feel comfortable doing that.

## How we work together

- **Be kind and respectful.** Treat others the way you'd like to be treated. Everyone here is volunteering their time.
- **Welcome all experience levels.** Whether you're new to dbt or have run it in production for years, your questions and contributions are valued.
- **Assume good intent.** Text can be misread. If something sounds off, ask before assuming.
- **Keep feedback constructive.** Review the code, not the person. Suggest improvements and explain the reasoning.
- **Be open to other ideas.** There's often more than one good way to build a feature. Discuss tradeoffs openly and help the project move forward.
- **Share what you learn.** Good issue descriptions, clear PRs, and helpful docs make it easier for the next person.

## Where this applies

This applies to all dbt-Workbench spaces, including issues, pull requests, discussions, and any other channel where people talk about the project.

Thanks for helping make dbt-Workbench a friendly place to build together.
